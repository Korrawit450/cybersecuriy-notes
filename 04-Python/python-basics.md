# Python Basics | พื้นฐานภาษา Python

Python is useful for automating repetitive security tasks. / Python ช่วยทำงานด้านความปลอดภัยที่ซ้ำ ๆ โดยอัตโนมัติ

```python
failed_logins = 3
threshold = 5
if failed_logins >= threshold:
    print("Review login activity")
else:
    print("Below review threshold")
```

**Exercise / แบบฝึกหัด:** Change `failed_logins` to 6 and observe the result. / เปลี่ยนค่าเป็น 6 แล้วสังเกตผลลัพธ์

This is a learning example, not a production detection rule. / ตัวอย่างนี้ใช้เพื่อการเรียนรู้ ไม่ใช่กฎตรวจจับสำหรับระบบจริง
