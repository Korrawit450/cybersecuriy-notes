# Basic Linux Commands | คำสั่งลินุกซ์พื้นฐาน

Run these only on your own Linux machine or practice environment. / ทดลองเฉพาะเครื่องของตนเองหรือแล็บที่ได้รับอนุญาต

```bash
pwd           # show current directory / แสดงโฟลเดอร์ปัจจุบัน
ls -la        # list files / แสดงรายการไฟล์
mkdir lab     # create folder / สร้างโฟลเดอร์
cd lab        # enter folder / เข้าโฟลเดอร์
printf 'hello\n' > hello.txt
cat hello.txt # read file / อ่านไฟล์
```

**Exercise / แบบฝึกหัด:** Create a folder and text file, then read the file. / สร้างโฟลเดอร์และไฟล์ข้อความ แล้วอ่านไฟล์
