# Common Ports | พอร์ตที่พบบ่อย

| Port | Typical service | ภาษาไทย |
|---|---|---|
| 22/TCP | SSH | เชื่อมต่อระยะไกลแบบเข้ารหัส |
| 53/UDP,TCP | DNS | ระบบชื่อโดเมน |
| 80/TCP | HTTP | เว็บที่ไม่เข้ารหัส |
| 443/TCP,UDP | HTTPS (including HTTP/3 over UDP) | เว็บเข้ารหัส |
| 25/TCP | SMTP | ส่งอีเมลระหว่างเซิร์ฟเวอร์ |

**Important / สำคัญ:** A port number alone does not prove which application is running. / หมายเลขพอร์ตอย่างเดียวไม่ยืนยันว่าเป็นแอปใด
