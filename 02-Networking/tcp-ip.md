# TCP/IP Basics | พื้นฐาน TCP/IP

**IP** addresses and routes packets between networks. / IP ใช้ระบุที่อยู่และส่งต่อแพ็กเก็ตระหว่างเครือข่าย

**TCP** provides ordered, reliable byte-stream delivery. / TCP ส่งข้อมูลแบบเรียงลำดับและตรวจสอบความครบถ้วน

**UDP** sends datagrams without built-in delivery guarantees. / UDP ส่งดาตาแกรมโดยไม่รับประกันการส่งถึงในตัวโปรโตคอล

**DNS** translates names to records such as IP addresses. / DNS แปลงชื่อโดเมนเป็นระเบียน เช่น ที่อยู่ IP
