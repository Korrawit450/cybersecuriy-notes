# OSI Model | แบบจำลอง OSI

Seven conceptual layers, top to bottom / 7 ชั้นจากบนลงล่าง:

7. Application — user-facing network services / บริการเครือข่ายที่แอปใช้
6. Presentation — data representation / การแปลงรูปแบบข้อมูล
5. Session — communication sessions / การจัดการเซสชัน
4. Transport — end-to-end delivery (TCP/UDP) / การส่งข้อมูลปลายทางถึงปลายทาง
3. Network — routing (IP) / การกำหนดเส้นทาง
2. Data Link — local frames (Ethernet) / เฟรมภายในเครือข่าย
1. Physical — signals and cables / สัญญาณและสายสื่อสาร

**Note / หมายเหตุ:** OSI is a teaching model; real internet protocols do not map perfectly to it. / OSI เป็นแบบจำลองเพื่อการเรียนรู้ โปรโตคอลจริงอาจไม่ตรงกับชั้นอย่างสมบูรณ์
