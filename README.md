- Learn cybersecurity fundamentals / เรียนรู้พื้นฐานไซเบอร์ซีเคียวริตี้

## ⚠️ Ethics | จริยธรรม

Only test systems you own or have explicit permission to test. Never publish credentials, private data, or unauthorized scan results.

ทดสอบเฉพาะระบบที่เป็นของตนเองหรือได้รับอนุญาตอย่างชัดเจนเท่านั้น ห้ามเผยแพร่รหัสผ่าน ข้อมูลส่วนบุคคล หรือผลการสแกนที่ไม่ได้รับอนุญาต
